# Defensa Tore
- A 2D tower defense game made in Unity for my Applied Mathematics for Games midterm project.
  
* All game art and UI were made by me.

* [Gameplay Video](https://drive.google.com/file/d/1uBKBe9qyPLkE65cMF2aoIQuTv9Q9ycLs/view?usp=sharing)

# Features

* Build and upgrade towers to defend your base.

* Survive 10 waves of increasingly difficult enemies.

* Fight different enemy types, including a final boss.

* Custom enemy movement and hit detection using mathematical calculations instead of Unity colliders and rigidbodies.
